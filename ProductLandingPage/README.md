# 🌸 Flores — Skincare Products E-Commerce Website

> **Beauty, care, and confidence — all in one place.**

Welcome to **Flores**, a modern skincare products e-commerce website designed to showcase beauty and skincare products in a clean, elegant, and user-friendly layout.

This project is a frontend development practice project where I will be transforming a Figma design into a functional webpage using **HTML and CSS**.

The goal is to recreate the design as closely as possible while strengthening my understanding of webpage structure, layout, styling, spacing, positioning, and responsive design.

---

## 🌿 About The Project

Flores is a skincare and beauty e-commerce website designed with a soft, clean, and elegant aesthetic.

The website will allow visitors to explore skincare products, learn more about the brand, discover trending products, read customer reviews, and explore recent blog posts.

This project is focused on turning a visual design into a real webpage using code.

---

## ✨ Planned Sections

The Flores website will include:

- 🏠 Header and navigation bar
- 🌸 Hero/intro section
- 💆‍♀️ Services section
- 👩‍🦰 About Us section
- 🛍️ Trending Products section
- 💬 Customer testimonials
- 📰 Recent Blog section
- 📸 Product/beauty content sections
- 📧 Newsletter/subscribe section
- 🔗 Footer section

## 🛠️ Technologies Used

- **HTML5** — For the structure and content of the website
- **CSS3** — For styling, layout, spacing, colors, positioning, and visual effects
- **Font Awesome** — For icons
- **Figma** — Used as the design reference
- **VS Code** — Development environment

---

## 🎯 Project Goal

The main goal of this project is to practice converting a **Figma design into a real webpage**.

Instead of simply looking at a design and admiring how it looks, I want to understand how each part of the design can be recreated using HTML and CSS.

This includes paying attention to:

- Layout
- Spacing
- Typography
- Colors
- Images
- Buttons
- Navigation
- Product cards
- Sections
- Alignment
- Backgrounds
- Responsive behaviour

---

## 🧩 The Challenge

One of the things I am looking forward to with this project is discovering how different it feels to recreate a design from scratch.

A design in Figma can look simple because everything is already perfectly positioned.

But when it is time to write the code, I have to ask:

> How do I structure this section?

> Which HTML element should I use?

> Should I use Flexbox or Grid here?

> How do I get this spacing?

> How do I position this image?

> What happens when the screen becomes smaller?

These are some of the questions I expect to answer as I build Flores.
